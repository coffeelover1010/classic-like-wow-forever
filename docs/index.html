WORLD OF WARCRAFT UI RESEARCH

ClassicForeverUI

A clean-room, Classic-inspired UI addon built as a Retail/Classic test harness today and a diagnostic launchpad for WoW Forever when addon access arrives.

Compatibility firstClient flavour, API, frame, and asset assumptions are isolated and reported at runtime.
No extracted artworkVisuals resolve through Blizzard-resident texture paths and atlases whenever available.
Forever unverifiedRun /cf diagnostic, /cf assets, and /cf frames to collect the actual client's details.

Current status

Version 0.8.0-alpha adds original dark artwork and metal trim to the character equipment page. Native equipment actions, buttons, stats, models, outfits, tabs and accessibility backgrounds stay in place. Other character pages and bag windows keep their native appearance. Type /cf for the main switch, twenty feature toggles and tools to inspect textures or open a report. Choices save automatically, and changes wait until combat ends. The addon includes Classic action bar, unit frame, minimap, cast bar and spellbook skins. Offline checks pass; in-game rendering and combat tests are still required. Retail is the development target, and Forever compatibility remains unverified.

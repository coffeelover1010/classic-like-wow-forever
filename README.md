# Classic Like WoW Forever

An unofficial community addon project for WoW Forever.

## Status

The repository is ready for development. Addon source files and target-client
testing are still pending.

## Development

- Keep the addon source in a self-contained folder named after its eventual
  `.toc` file.
- Record the target client version and test results once the addon arrives.
- Do not commit saved variables, account data, or downloaded third-party
  libraries without reviewing their licenses.
